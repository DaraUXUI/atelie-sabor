# Ateliê do Sabor — Landing page

Landing page de pré-inscrição para dois cursos de culinária (Culinária Essencial e Culinária Kids). Projeto de protótipo com cliente fictício.

- Página única em HTML, CSS e JavaScript, sem dependências.
- Sem back-end: nenhum dado do formulário é enviado ou armazenado.
- Planejamento e decisões de UX em [PLANO.md](PLANO.md).

## Como abrir

Abra o arquivo `index.html` no navegador (a pasta `images/` precisa ficar ao lado dele).
Ou, com um servidor local:

```bash
python3 -m http.server 8765
```

e acesse http://localhost:8765/index.html.

## Créditos

Fotos: [Unsplash](https://unsplash.com) (uso gratuito). Imagens ilustrativas, sem relação com o ateliê. Nome, endereço, telefone e e-mail são fictícios.
